# Drafts

Not authoritative for current behavior. The design is
[`../design/ipow-protocol.md`](../design/ipow-protocol.md), with the
application and feature specs in [`../specs/`](../specs/).

What is here:

- **The build plan**: [`ipow-build-plan.md`](ipow-build-plan.md), the
  order in which the protocol of `ipow-protocol.md` is built. A plan, not
  a spec.
- **Dated records of live runs**: [`live-run-log.md`](live-run-log.md)
  (deploys, live transactions and incidents, with their lessons) and
  [`ipow-testnet-run-2026-10-02.md`](ipow-testnet-run-2026-10-02.md) (the
  protocol's first job taken end to end on Sepolia, with its timeline and
  costs, and what it teaches the SDK and Greatwall.finance). History, not
  spec. New live runs are logged here.
- **Unratified proposals**: none at the moment. A design for something
  not yet built and verified goes here, not into `design/` or `specs/` as
  if it were already true. Once built and verified it moves to `specs/`
  or into the design doc; otherwise it is dropped.

Built specs that started here (Conversion, the tunnel, BETA, the vault,
genesis, the SDK, the other networks) are in [`../specs/`](../specs/).
Designs of the retired generation are in [`../archive/`](../archive/).
